# script_shell_audit_system

Command Substitution :
La construction $(...)
Exécute la commande à l'intérieur des parenthèses, capture ce qu'elle affiche sur la sortie standard, et remplace l'expression entière par ce résultat.


Escape Sequences	Significance
\n	                new line
\r	                carriage return
\t	                horizontal tab
\b	                backspace
 \\	                backslash
